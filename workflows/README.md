# Automation Workflows

This folder documents the core business automation flows designed for the Production Cost & Inventory Automation system.

## Core Workflows

### 1. Raw Material Purchasing
Purchase records → Cost calculation → Raw material inventory update

### 2. Production
Production batch → Formula/material usage → Production cost calculation → Finished inventory

### 3. Inventory
Purchases → Production → Sales → Inventory movements

### 4. Sales
Customer order → Order items → Batch/cost tracking → Revenue

### 5. Profitability
Sales revenue → Product cost → Expenses → Profit & Loss

## Security

No API keys, credentials, passwords, or private business data should
be stored in this repository.
